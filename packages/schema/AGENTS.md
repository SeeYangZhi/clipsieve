# packages/schema/ — AGENTS.md

Single source of truth for every data contract. JSON Schema draft 2020-12, one file per top-level type plus `common.json` for shared `$defs`.

## Contract

- Field names are snake_case. Every object sets `additionalProperties: false`, except explicit maps, which set it to the value schema, and `RunEvent.payload`, which is deliberately open (`additionalProperties: true`).
- Cross-file references use `"$ref": "common.json#/$defs/Name"`. `merge.py` and `generate.ts` fold everything into one root schema before generation; a `$def` name must be unique across all files.
- A union that code imports by name gets its own `$def` (e.g. `Question` holds the `oneOf` of the three question types).
- Generated outputs: `backend/clipsieve/models.py` (Pydantic v2, extra forbid) and `frontend/src/lib/types.ts`. Both begin with `GENERATED by packages/schema; do not edit`. Every `$def` and every file title except `Common` is a named export in both.
- After any schema change run `bun run schema` at the repo root and commit the regenerated files. CI runs `bun run check:schema` and fails on drift.
- `RunEvent.payload` is an open object here; its per-type shape is enforced in `backend/clipsieve/events/writer.py`. Keep the table in `docs/superpowers/plans/2026-10-03-clipsieve-v0.1-00-overview.md` in sync with that code.

## Generated output gotchas

- Enums are `StrEnum`, so members compare equal to plain strings.
- `LanguageMode.translate_` is the member for `"translate"`. Writing `LanguageMode.translate` resolves to `str.translate`. Use `LanguageMode("translate")` or compare against `"translate"`.
- Inline enums get order-dependent generic names (`Type`, `Type1`, `Kind`, `Source`, ...). Do not import them; compare against string values.
- `date-time` fields are `AwareDatetime` and reject naive datetimes. Always use `datetime.now(UTC)`.
- `Question` is a plain union alias (`type Question = ChoiceQuestion | ScoreQuestion | NoulQuestion`), not a `RootModel`, so `isinstance(q, ChoiceQuestion)` works on `RubricPack.questions` values.
- Constraints use `Annotated`, so constrained map values stay plain (`Plan.quantities` is `dict[str, int]`).
- Bounded arrays (`persona_fit_criteria`, `keyframes`, `ScoreQuestion.criteria`) are plain `string[]` in TS. Lengths are enforced by Pydantic only.
- TS objects are interfaces; enums are string-literal unions, not TS `enum`s.
